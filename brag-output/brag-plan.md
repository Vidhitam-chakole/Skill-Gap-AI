# Brag Plan: Skill Plus AI (30-Second Extended Edition)

## What is this app?
Skill Plus AI is a next-generation career intelligence and profile review platform that extracts and cross-examines a developer's official LinkedIn Profile PDF against their public GitHub repositories to identify critical competency gaps, generate adaptive sprint roadmaps, and provide a context-aware AI mentor (*PulseBot*).

## The angle
Screen Studio style high-energy SaaS product demo with a neo-brutalist aesthetic and 2.5D camera tracking. Demonstrates the complete step-by-step product walkthrough in 30 seconds:
1. Instant LinkedIn PDF extraction and ATS readiness scoring
2. Deep GitHub profile code review and language byte-weighting
3. Synthesized Adaptive Career Roadmap with concrete milestone sprints
4. Interactive PulseBot Assistant chat answering personalized prep questions

## Hook (first 5 seconds)
Dynamic Screen Studio camera swoop into the cream-and-orange neo-brutalist hero: "SKILL PLUS AI" slams down with neon stickers ("100% FREE", "ZERO SIGN-IN"), while PulseBot hovers in on a spinning bamboo copter with happy pixel eyes (`^ ^`) and speech bubble: *"Tired of guessing your tech gaps? Let's audit your stack!"*

## Key moments (the middle)
- **Feature 1 — LinkedIn PDF Extraction (5.0s – 11.0s)**: Camera pans to the PDF dossier parser. An official LinkedIn resume PDF is uploaded and parsed in real time, revealing claimed skills and an ATS Readiness Score of 87.
- **Feature 2 — GitHub Profile Code Review (11.0s – 17.0s)**: Camera glides to the GitHub profiler scanning `@developer` across 42 repositories, displaying byte-weighted language bars (TypeScript 54%, Python 32%, Go 14%) and commit velocity.
- **Feature 3 — Adaptive Career Roadmap (17.0s – 23.0s)**: Synthesizes real signals from both LinkedIn and GitHub to generate a 4-week sprint roadmap (Distributed Caching, CI/CD) and 94% skill verification score.
- **Feature 4 — PulseBot AI Career Coach (23.0s – 30.0s)**: Full interactive chat demonstration where PulseBot answers personalized career questions, followed by a wide 3D workstation outro with a bold CTA.

## Outro / punchline
Camera pulls back to a cinematic 3D angled workstation perspective. Final punchline banner: *"100% FREE FOREVER • ZERO SIGN-IN"*, followed by the vibrant orange CTA button *"LAUNCH SKILL PLUS AI →"* and `skillplusai.vercel.app`.

## User flow shown
Entry: Upload LinkedIn PDF & enter GitHub handle → Synthesis: Cross-examine resume claims against real repository code → Roadmap: 4-week milestone sprint plan → PulseBot: Personalized AI coaching chat.
