# Skill Verifier Frontend Component

The interactive UI for the Anti-AI Code & Skill Authenticity Verifier.

## Features

- **Pre-loaded GitHub Detected Languages**: Automatically reads primary languages discovered from the user's GitHub profile.
- **Language Switcher**: Seamlessly test across C, Python, JavaScript, C++, TypeScript, or Java.
- **10-Step Interactive Assessment Flow**:
  - Live progress bar & question counter.
  - Formatted code snippet box with monospace font and custom highlight accent.
  - 4 selectable multiple-choice cards with keyboard / click responses.
  - Question jump dots highlighting answered vs unanswered questions.
  - Previous / Next navigation controls with submission confirmation.
- **Forensic Report Screen**:
  - Authenticity status badge (Verified vs AI-Augmented vs Suspect AI Code).
  - Score dial with percentage score.
  - AI forensic insight box detailing why blind AI copy-pasting fails.
  - Tested core mechanics breakdown bars.
  - Detailed Question-by-Question review with complete technical explanations.
  - Quick action buttons to retake test, test other languages, or discuss gaps with the Local AI Career Assistant.
